# Contributing

Thanks for contributing 🙌

## 1) Fork and clone

```bash
git clone https://github.com/<your-username>/data_privacy.git
cd data_privacy
```

## 2) Create a branch

```bash
git checkout -b my-change
```

## 3) Make changes and commit

```bash
git add .
git commit -m "Short message about your change"
```

## 4) Push your branch

```bash
git push origin my-change
```

## 5) Open a Pull Request

On GitHub:
1. Open your fork.
2. Click **Compare & pull request**.
3. Add a clear title + short description.
4. Submit PR.

**Good to go!!!**
